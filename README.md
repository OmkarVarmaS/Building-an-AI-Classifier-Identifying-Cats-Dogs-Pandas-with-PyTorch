# Building an AI Classifier: Identifying Cats, Dogs & Pandas with PyTorch

## 🐱🐶🐼 Building an AI Classifier: Identifying Cats, Dogs & Pandas with PyTorch

## This project demonstrates how to build a deep learning image classifier using PyTorch to identify three animal categories:

### Cats 🐱
### Dogs 🐶
### Pandas 🐼

The model is trained on labeled image datasets and uses a Convolutional Neural Network (CNN) to learn visual features that distinguish between these animals. The project covers data preprocessing, model training, evaluation, and prediction on new images.

## 📌 Project Overview

Image classification is one of the most common applications of deep learning. In this project, we train a CNN model to classify images into one of three categories: cat, dog, or panda.

## The workflow includes:

#### Loading and preprocessing image data
#### Creating training and validation datasets
#### Building a CNN architecture in PyTorch
#### Training the model
#### Evaluating performance
#### Making predictions on unseen images


## 🎯 Objectives

#### Understand image classification using PyTorch
#### Learn how CNNs extract visual features
#### Train a multiclass classifier
#### Evaluate model accuracy and loss
#### Deploy the trained model for inference


## 🛠️ Technologies Used

#### Python 3.9+
#### PyTorch
#### Torchvision
#### NumPy
#### Matplotlib
#### OpenCV

## 🔄 Data Preprocessing

## Images are:

#### Resized to 224×224 pixels
#### Normalized using ImageNet statistics
#### Converted into PyTorch tensors
#### Augmented using:
#### Random horizontal flips
#### Random rotations
#### Random crops

## 📈 Evaluation Metrics

## The model is evaluated using:

#### Accuracy
#### Precision
#### Recall
#### F1-Score
#### Confusion Matrix
